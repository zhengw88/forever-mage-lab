# Personal Forever Mage Lab

An independently maintained Mage simulator owned by **zhengw88**, forked from
[opitaru-sys/forever-mage-lab](https://github.com/opitaru-sys/forever-mage-lab).
The Python models, cast-by-cast simulation, JavaScript calculator and original
history are here so results can be inspected and reproduced locally.

**Status: experimental current-mechanics research runs; migration remains incomplete.**
The personal research layer provides provisional Arcane, Fire and Frost comparisons
with matched inputs. Certified in-game rankings remain blocked. The inherited
69893 baseline is preserved as a labeled historical archive.
We do not use MythicSim rankings as evidence of our own simulator's result.

## Run locally

Requires Python 3.12+ and Node 22+. No external simulator or API key is needed.

```sh
git clone https://github.com/zhengw88/forever-mage-lab.git
cd forever-mage-lab
python lab.py status
python lab.py validate
python lab.py compare --historical --fights 1000 --seed 1 --seconds 300 --output results/baseline.json
python build_personal_site.py
python -m http.server 8000 --directory _site
```

Open `http://localhost:8000` for the research simulator and day-one guide;
`historical.html` holds the inherited calculator with its historical warning. The JSON comparison records all inputs, talents, source hashes, revision,
per-spell damage, mana diagnostics, seed and sampling uncertainty. `compare`
without `--historical` is blocked while the migration is incomplete.

The Python and JavaScript research schedulers integrate Arcane Blast/Wrath,
Missile Barrage, Fire effects, Ice Lance, Winter's Chill and Ice Barrier. Talent
builds pass the extracted contract; server validation, a complete current spell
snapshot, wider talent/rotation search and realistic leveling survival remain
open. See [mechanic evidence](CURRENT-MECHANICS.md), [model limitations](SIMULATION.md)
and the [provisional ranking](PROVISIONAL-RANKING.md). The leveling point order is
practical guidance, not a proven optimum.

`index.html` is the historical artifact generated by `python src/build.py`.
`build_personal_site.py` stages `current.html` as the published homepage, plus the
leveling guide, reports and versioned assets. Personal Pages publishes merged
`main` only after numerical, artifact and current-page browser gates. Future PRs
require owner merge authorization. The two known historical browser failures are
documented in `REBUILD.md`.
