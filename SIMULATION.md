# Experimental event simulation

This personal fork now runs independent Python (`sim_engine.py`) and JavaScript
(`sim-engine.js`) event simulations. The personal website runs its JavaScript
engine locally in a worker. No ranking service or external simulator is called.
The historical engines and their share links remain in the historical archive.

**Current rankings remain blocked.** A runnable model is not a verified model of
the live server. The October 30 hotfix target is 1.60.1.70707; source review is
November 3, 2026 UTC (including November 2 official notes). No newer upstream commit than `a331552` was found.

## Reproduce

```sh
python lab.py experiment --fights 200 --seed 10001 --output experiment.json
python lab.py experiment --options options.json --output experiment.json
python sim_report.py
python sim_report.py --check
python sim_test.py
python lab.py validate
python build_personal_site.py
python tests/current_page_check.py
python tests/page_check.py
```

`options.json` is an object overriding `sim-defaults.json`. Both engines reject
unknown options, invalid ranks and illegal talent allocations. Default presets
spend the full level budget; custom CLI builds may intentionally leave points
unspent for controlled tests. The website requires full-budget custom builds.
The current keyed talent codec includes its tree version. Old `#b-`, `#race-`
and `#lvl-` URLs redirect to the historical calculator, without reinterpretation.

`simulate(school, options, build)` returns spell damage, casts, mana accounting,
downtime, optional event traces and complete inputs. Python `Fight` is also
available for controlled mechanic experiments. JavaScript exports the same
contract through `createMageSim` in the browser or `require('./sim-engine.js')`.

## Evidence, facts and hypotheses

`sim-data.json` has per-rank provenance and source references. It is generated by
`make_sim_data.py`, which extracts the inherited raw client records without
executing the historical optimizer. Unchanged 69893 rank values are hypotheses,
not a claim that all ranks were re-extracted from 70707. The 70532 coefficient
extraction at https://wowforeverhelper.com/spells/mage supports a second, dated
check but cannot establish later server hotfix values.

The source register and `CURRENT-MECHANICS.md` link official notes and individual
talent/ability records. Implemented research mechanics include:

- Blast's 1.5-second cast, 12%-Intellect stacks, four-stack cap, 18-second first-
  application expiry, base-mana cost and cost growth; Wrath's cast, cooldown and
  maximum-mana scaling; one-use Barrage and channel tick scheduling.
- Fire Blast's Heating Up contribution, Pyro consumption, Presence of Mind,
  personal Fire effects, Scorch, rolling Ignite and cooldowns.
- Ice Lance's eight-second cooldown shared with Fire Blast and frozen multiplier, Winter's Chill
  stacking/Cone consumption, separate Barrier and shield-survival windows,
  Fingers of Frost charges and a Cold Snap policy.
- Rank availability, legal level-adjusted talent presets, cast/GCD timing,
  bounded resources, consumables, regeneration, Evocation, racial hypotheses,
  multi-target damage and safe-target kill/recovery throughput.

Important limitations and explicit alternatives:

| Mechanic | Research default | Remaining uncertainty / controls |
| --- | --- | --- |
| Shared Blast/Lance cooldown | casting either sets both timers to the casting spell's cooldown (8s, or 6/7s for talented Fire Blast) | `shared_blast_lance_base=true` tests an unreduced 8s category; talent/category interaction unvalidated |
| Cold Snap | resets Frost spells only, leaving Fire Blast's timer | `cold_snap_resets_fireblast=true` tests resetting the shared category too; unvalidated |
| Ice Lance coefficient | 0, as extracted | `ice_lance_coef`; 0.143 and 0.429 are sensitivity probes, not calibrated answers |
| Wrath coefficient | 1 from older 70532 extraction | `wrath_coef`; lower-rank growth unverified |
| Blast application | cast completion, including a miss | `ab_apply` can defer to impact; snapshots use SP at cast start |
| Winter's Chill | 15 seconds, added coefficient inside stack multiplier, consumed on landed Cone | `winter_duration`, `winter_order`, `cone_consume_on_miss` |
| Barrier | +15% and +5% additive; shield lasts 10 seconds | lifetime, refresh policy and multiplicative alternative; incoming damage/absorption not simulated |
| Fingers of Frost | 15% chill proc; 1/2 charges, works on bosses | `fof_on_boss`; cast-start charge consumption and trigger phase require logs |
| Ignite | 40% of crit damage at rank 5; rolling remaining bank over two ticks, preserving next tick | munching, simultaneous application and server rollover require logs |
| Fire effects | caster-owned effects, Scorch and Ignite; up to four | DoTs snapshot modifiers; mixed Frostfire benefits but does not count as a unique Fire Power effect |
| Hit/resistance | 83% base hit vs +3, 1% miss floor, 6% average partial resistance | separate controls; resistance is an average multiplier, not a sampled resist table |
| Mana | inherited base-mana/Intellect and Spirit formula, 2-second ticks, Mage Armor from level 34 | regeneration and tick phase need server validation; all input stats are after buffs, before talent/racial modifiers |
| Troll Berserking | 15 seconds, 10% haste | 70755 extraction now corroborates 15 seconds; the archived 10-second case tests older data; `berserking_duration` and `berserking_haste` |
| Other racials | Human crit/Spirit, Gnome pool and eight-second direct bonus/cost reduction, Orc SP, Skyborne haste/regen, Undead caster proc with 15-second ICD | direct/periodic scope and proc rules need logs; no out-of-raid attunement bonus assumed |
| Periodic crits | off | `periodic_crit`; periodic events can advance Combustion without consuming its three direct crits |
| Wand | first shot after at least 0.5 seconds stationary; fixed DPS, no miss/crit/procs | simple mana-recovery fallback; no movement model |
| Leveling / AoE | safe stationary targets; highest available ranks, no books unless enabled | excludes incoming damage, deaths, pathing, group XP sharing, immunities and crowd-control survival |

Clearcasting and Barrage attempt at most one proc per cast, on its first landed
hit. Undead attempts on landed direct/channel hits; periodic events do not
trigger it in this hypothesis. Those scopes require combat-log validation.

All damage is evaluated against identical target settings. In mixed-school
spells this first model applies both eligible talent families; resistance still
uses the same explicit scalar. It has no threat, pushback, latency, movement,
pet, target resistance-debuff or raid-buff simulator. Improved Channeling,
Subtlety and defensive/control talents can therefore have no throughput effect
in this stationary, zero-incoming-damage encounter. Not every talent is an
implemented combat effect: legality is separate from mechanic coverage.

Consumables assume a prepared inventory of one available gem of each rank and
Major Mana Potions from level 49, with separate 120-second cooldowns. Low-level
potion ranks are not modeled. Evocation is eight seconds and has an assumed
480-second cooldown. Damage to finite-health targets is capped at remaining
health. Channels retarget the first living target on each tick; this optimistic
pack behavior needs validation. Dots on killed targets deal no further damage.

The priority policies are explicit in each port. Cold Snap is used when a frozen
charge is available but Lance is cooling down. Fire maintains its own Scorch;
other schools do not receive an external Scorch debuff. Barrier is refreshed by
policy even if no shield remains. At range, Cone is unavailable. Movement to
enter range is not modeled. A spell started before the time limit consumes mana;
only impacts/ticks at or before the limit count as damage.

## Experiments and uncertainty

`current-experiments.json` is generated with input hashes, 35 matched scenarios,
200 fights per school, seed range 10001–10200 and alphabetical school order.
Sampling intervals are mean ± 1.96 standard errors, not a bound on mechanic error.
The same seed range does not imply paired identical proc draws between schools.

The finite search considers 10 Arcane, 12 Fire and 4 Frost policies using training
seeds 1–60. Selected policies are evaluated with disjoint held-out seeds and stay
fixed across the sensitivity scenarios. This search is neither a global talent
optimizer nor proof that a selected policy is best in other encounters. The
interactive website starts from documented baseline policies, not the archive's
selected policies. Full configurations and rotations accompany every archive row.

Safe-target XP/hour includes modeled kill time, fixed walking and mana recovery.
The optional 20% dungeon adjustment applies only when `dungeon=true`; it is not
applied to open-world kills. It excludes party XP division and dungeon pacing.
Do not treat this metric as a leveling recommendation.

## Tests and release

The targeted suite uses independent arithmetic for Fireball, Wrath, Cone, Blast
costs/expiry, Barrier windows and Ignite bank conservation; it also checks 180
level/build combinations, resource conservation, channel timing, cooldowns,
Pyro/Presence of Mind and Barrage, rank availability, input rejection and 57
full Python/JavaScript seeded traces. Generated defaults/data/reports must be
fresh. Browser tests cover desktop/tablet/phone, local runs, input errors,
versioned sharing and historical redirect. The untouched historical browser
suite has two documented baseline failures; see `REBUILD.md`.

Deployment is only to `zhengw88/forever-mage-lab`, explicitly requested by the
owner in this session. The Pages artifact is built in `_site` with a current
research homepage and a historical archive. Publishing does not merge the open
PR or write upstream. Future maintenance still requires explicit deployment
approval; automatic merging and routine automatic publishing remain disabled.

## Day-one companion

`leveling.html` is an authored solo-questing recommendation with 51 sequential
allocations checked in both languages. It deliberately prioritizes control and
Ice Barrier at 40 rather than a simulated raid winner. It assumes no bonus
Legacy points and requires no respec. `leveling-plan.json` is the single source
for its point order; run `python build_leveling_guide.py` after edits.

The guide loads the exact Frost build and manually entered stats into a shared
experiment. Other schools retain the research presets. Finite-target results
show mean kill time only when every trial kills its targets, mana spent and
modeled full-refill recovery. Every trial starts at full mana. These metrics do
not model root breaks, incoming damage, movement, deaths or continuous farming.
The guide does not use their omission to declare control talents inferior.

## Complete November 2 Mage audit

See `MAGE-NOV2-COVERAGE.md` for every Mage bullet, its implementation and tests.
Flamestrike later critical ticks now contribute to Ignite; periodic criticals
remain disabled by default. The paired AoE sensitivity cases hold all inputs
fixed and toggle only `flamestrike_periodic_ignite` with periodic criticals enabled.
Both engines return `defensive_stats` (Resilience armor and Warding multipliers).
Incoming damage, shield depletion and Warding negation are executable in both
replay ports using explicit observed inputs, not in the safe-target scheduler.
This distinction remains a blocker for survival-aware leveling recommendations.

## Provisional ranking artifact

`ranking_report.py` reselects each school's best tested policy for nine encounters,
using 100 training fights and 500 separate evaluation fights per school. It keeps
the three source-contract legal talent presets fixed; this is not exhaustive
build/rotation optimization. `provisional-rankings.json` and `PROVISIONAL-RANKING.md`
include ranks, sampling intervals, mana downtime, spell breakdowns and a separate
view of the existing 35 fixed-policy scenarios. No mechanics or calibration values
change for this report. The owner explicitly requested these provisional rankings;
certified rankings and the historical comparison release guard remain blocked.
